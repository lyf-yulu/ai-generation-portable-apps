# 真人类过小参考图规范化设计

## 背景

真人类任务“茶壶青蛙”的第一张参考图在飞书文档及飞书媒体下载接口中均为
`216×384` PNG。应用原样保存了该文件，没有执行压缩。火山 Asset API 要求图片
宽高均至少为 300px，因此 `CreateAsset` 返回
`InvalidParameter.WidthTooSmall`，任务未进入视频生成阶段。

## 目标

- 真人类任务上传火山 Asset 前，自动处理宽或高小于 300px 的图片。
- 只放大上传副本，不修改飞书文档、本地原始输入或动画类、Nano Banana 路线。
- 已满足尺寸要求的图片保持原始字节不变。
- 火山 Asset 的 HTTP 4xx 错误保留错误码和原因，避免再次只显示泛化失败。

## 处理规则

1. 在 `VolcengineAssetClient.ensure_image_asset` 的公开托管步骤前读取图片。
2. 若宽和高均不小于 300px，直接使用原始字节。
3. 若任一边小于 300px，按下列比例等比放大：

   `scale = max(300 / width, 300 / height)`

4. 新宽高向上取整，使用 Pillow 的 Lanczos 重采样。`216×384` 将得到约
   `300×534`。
5. PNG 保持 PNG，JPEG 保持 JPEG；只将生成的内存字节交给临时公开托管服务。
6. 无法解码的图片或不受支持的格式按输入校验失败处理，不提交 Asset。

## 错误处理

- 网络错误、超时和 HTTP 5xx：临时错误，可重试。
- 火山 HTTP 4xx：供应商终止错误，不自动重复付费提交。
- 4xx 的 `ResponseMetadata.Error.Code` 和 `Message` 写入技术错误信息，用户界面
  至少显示可理解的尺寸或格式原因。

## 测试

- 过小 PNG 会被等比放大到两边均不小于 300px。
- 合规图片上传字节保持不变。
- 原始本地文件在处理前后哈希一致。
- 火山 4xx 尺寸错误被归类为供应商终止错误，并保留错误码。
- 现有真人 Asset 创建、复用、轮询测试继续通过。
