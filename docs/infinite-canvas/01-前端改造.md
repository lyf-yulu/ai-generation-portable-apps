### 2.3 API 前缀（最关键，且不能用直觉做法）

浏览器请求必须是 `/infinite-canvas/api/v1/...`，Portal 剥掉前缀后子应用收到 `/api/v1/...`（`portal/app.py:1973`），两端路由都不用改。问题在于**怎么加这个前缀**。

**❌ 不要直接改 `API_PREFIX` 常量。** 源码里有 **40+ 处硬编码**的 `/api/v1/...` 字面量（`projects.ts:9-17`、`jobs.ts:4-6`、`assets.ts:47,61`、`models.ts:3`、`session.ts:3`、`prompt-skills.ts:7,16`、`activity.ts:23-24` 等），它们都要过 `safeApiPath` 的前缀校验（`client.ts:30`）。把常量改掉，这 40 处会**全部抛 `unsafePathError`**。

**✅ 正确做法**：保持校验仍然针对裸 `/api/v1/`，但让 `safeApiPath` **返回**带挂载前缀的路径，并且**幂等**（已带前缀的再传进来也不出错）。这样 40 个调用点一处都不用动。

`infinite-canvas/web/src/api/client.ts`：

```diff
 const API_PREFIX = "/api/v1/";
+// 挂载点。构建期 BASE_URL = "/infinite-canvas/"；npm run dev 时为 "/"，
+// 下面的推导会退化成恒等变换，本地开发行为不变。
+const BASE = import.meta.env.BASE_URL.endsWith("/") ? import.meta.env.BASE_URL : `${import.meta.env.BASE_URL}/`;
+const MOUNTED_PREFIX = `${BASE}api/v1/`;
 let csrfToken: string | null = null;
```

```diff
 export function safeApiPath(path: string) {
     if (!path.startsWith("/") || path.startsWith("//") || /^[a-z][a-z0-9+.-]*:/i.test(path)) throw unsafePathError();
-    const pathname = path.split(/[?#]/, 1)[0];
+    // 幂等：允许传入已挂载的路径，便于 assetUrl() 之类的返回值再被 apiFetch 消费。
+    const bare = path.startsWith(MOUNTED_PREFIX) ? path.slice(BASE.length - 1) : path;
+    const pathname = bare.split(/[?#]/, 1)[0];
     if (!pathname.startsWith(API_PREFIX)) throw unsafePathError();
     for (const segment of pathname.split("/")) {
         const decoded = fullyDecode(segment);
         if (decoded === "." || decoded === ".." || decoded.includes("/") || decoded.includes("\\")) throw unsafePathError();
     }
-    return path;
+    return `${BASE}${bare.slice(1)}`;
 }
```

`BASE.length - 1` 是让切片正好落在 `api` 前面那个 `/` 上：`"/infinite-canvas/"` 长 17，`slice(16)` 得到 `"/api/v1/..."`。`BASE === "/"` 时 `slice(0)` 是恒等，开发模式零影响。

幂等性为什么必要：`assetUrl(id)`（`client.ts:37-39`）的返回值既被当作 `<img src>` 用（`assets.ts:33` 的 `content_url`），又被当作 `apiFetch` 的入参用（`assets.ts:52` 的 `deleteMediaAsset`）。不幂等的话第二种用法必炸。

### 2.4 绕过 `safeApiPath` 的两处漏网

`safeApiPath` 收口了绝大部分，但有两处自己拼路径：

**① `src/components/canvas/media-collection-node.tsx:54`** —— 直接拼字符串当 `src`：

```diff
-const source = `/api/v1/assets/${encodeURIComponent(item.assetId)}/content`;
+const source = safeApiPath(`/api/v1/assets/${encodeURIComponent(item.assetId)}/content`);
```
（同文件补 `import { safeApiPath } from "@/api/client";`）

**② `src/services/api/video.ts:29`** —— 用裸前缀做校验：

```diff
-if (result.url?.startsWith("/api/v1/assets/")) return { url: result.url, ... };
+if (result.url && isMountedAssetUrl(result.url)) return { url: result.url, ... };
```

在 `client.ts` 导出一个判定函数供其使用：

```ts
export const isMountedAssetUrl = (url: string) =>
    url.startsWith(`${MOUNTED_PREFIX}assets/`) || url.startsWith(`${API_PREFIX}assets/`);
```

**③ `src/api/assets.ts:61`** 的 XHR `request.open("POST", safeApiPath("/api/v1/assets"))` —— 已经过 `safeApiPath`，改动后自动带上前缀，**无需修改**。

### 2.5 持久化的 URL 一律存裸路径

画布节点会把生成结果的地址存进项目文档（`services/api/video.ts:29` 存 `result.url`）。**必须存裸 `/api/v1/...`，挂载前缀只在读取/渲染时加**。

理由：挂载点是部署决定（今天是 `/infinite-canvas/`，将来上公网可能变），存进文档就把部署细节焊死进了用户数据，改一次挂载点所有历史画布的图片视频全裂。

实现上这是自然结果——服务端返回裸路径，`protectedResultUrl()`（`jobs.ts:38-41`）和 `content_url` 在读取时才过 `safeApiPath` 挂载。**别在服务端返回带前缀的 URL**，这条在 `03-契约翻译层.md` 里会再强调一次。

## 步骤 3 — 裁掉与 Portal 重复的页面

Portal 已经有登录、账号管理、统计。画布里这几套必须去掉，否则用户看到两套账号体系和两份对不上的统计数字。

### 3.1 路由表

`infinite-canvas/web/src/router.tsx` 删除这些条目：

| 删除 | 理由 |
|---|---|
| `{ path: "/login", ... }` | Portal 负责登录；会话由服务端合成，永远不会走到这里 |
| `{ path: "/usage", ... }` | Portal「统计」tab 是唯一口径 |
| `{ path: "/admin/users", ... }` | Portal「账号管理」是唯一口径 |
| `{ path: "/admin/models", ... }` | 模型来自 seedance/nano-banana 的 providers.json，不在画布里派发 |
| `{ path: "/admin/usage", ... }` | 同上 |

对应删掉顶部 5 个 import（`LoginPage` / `UsagePage` / `AdminUsersPage` / `AdminModelsPage` / `AdminUsagePage`），以及 `RoleGate` 的 import（不再有使用者）。

**保留 `AuthGate`。** 它不只是路由守卫——`auth-gate.tsx:14-28` 调 `loadSession()` 后会触发 `setStorageScope({environment, userId})`，而 `storage/scope.ts:25-27` 用它决定 IndexedDB 库名 `ai-creation-canvas:<env>:<userId>`。删掉 AuthGate 会让本地画布存不进去（`scope.ts:42` 对空值直接抛错）。

保留的路由：`/`、`/canvas`、`/canvas/:id`、`/assets`、`/tasks`、`*`。

